# Bang Na research record

[← Research and code](../README.md)

**Zihao Lin and Lei Shao.** *Residential types, street interfaces and variation in
the green view index along public streets in a peripheral TOD station area:
Bang Na, Bangkok*. Research manuscript; this repository does not assert journal acceptance.

The README reproduces Figures 2 and 5 from the **22 October 2026 English v4 manuscript**.
Both PNGs are unchanged from the previously shared portfolio, preserving original
labels, intervals and map credits (OpenStreetMap; Microsoft / Esri).

GVI includes vegetation only after a 40-pixel bottom crop. The 289 street-view
points include 267 valid interface observations. Missing interface scores remain
missing. Models describe conditional associations across 25 areas.

The main runner uses the included numerical tables. Original image inference and
GIS scripts in [legacy/](../legacy/README.md) require their external inputs and
historical environment. [PROVENANCE.md](../PROVENANCE.md) records the script sources.
